# 0.2 需求与验收

1. Web 客户端在 apps/web，Electron 客户端在 apps/desktop，API 在 services/api；API 不依赖 Next.js。
2. Web 与 API 可以分别构建和启动。共享数据校验在 packages/contracts，浏览器不得导入数据库或服务端模块。
3. 已有角色、会话、记忆数据保持可读；原创角色新增，旧角色归档展示，不删除聊天。
4. 默认语音提供明确的准备、播放、停止、失败状态；切换会话取消请求，避免多个音轨重叠。仅保留日常语音，移除较慢的 H3 演绎。
5. 验收包含类型检查、单元测试、独立 API HTTP 测试、生产 Web 构建及桌面资源检查。自然度需要实际试听，不以接口 200 代替听感评价。
