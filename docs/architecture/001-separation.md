# ADR 001：独立 API 与客户端

状态：已实施；验证范围见 ../validation/0.2.md。

保留 Next.js 作为 Web UI 宿主；将业务路由迁出为标准 Request/Response 处理器，由独立 Node HTTP 服务承载。Web 只提供同源转发，避免浏览器跨域配置且不承载业务或数据库访问。Electron 管理 Web 与 API 两个子进程，数据路径继续使用 CHARACTEROS_DATA_DIR。

选择轻量 HTTP 适配器是为了保留已有流式协议，避免同时重写业务框架。协议与 Zod 校验提取到共享包；CI 检查客户端不得反向依赖服务端。

开发流程：先更新需求与接口，记录方案取舍，再实现，最后记录验收结果。目录迁移本身不作为前后端分离验收依据。
