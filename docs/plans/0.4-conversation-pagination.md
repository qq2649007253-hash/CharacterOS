# 会话列表分页

首次加载 20 条，按更新时间和 ID 倒序。GET /api/conversations 接受 characterId、limit（1–50，默认 20）和 cursor；返回 conversations 与 nextCursor，null 表示到底。旧调用方仍能读取 conversations，但需要消费 nextCursor 才能取得全部历史。

服务端使用游标条件和匹配复合索引，每次最多取 limit + 1 条。前端提供加载更多、加载中、失败重试和已显示全部状态；追加记录按 ID 去重，新会话直接加入顶部，角色页面以 ID 为 key 隔离列表状态。游标属于实时列表，不是跨客户端的冻结快照：其他窗口更新旧对话可能改变排序，重新进入角色会读取最新首页。

验证：隔离数据库中创建 46 条对话，其中 45 条更新时间相同；遍历分页记录无重复或遗漏。第一页后新建的对话不挤占后续页，刷新首页后可见。空列表、非法游标、非法页大小均验证通过。25 项单元测试通过。
