# 默认陪伴与角色分享

每个账号第一次读取角色列表时，在事务内补齐三位默认角色并记录初始化标记。已有同名角色不覆盖；后续删除默认角色不会自动恢复。

角色卡提供分享链接、撤销和角色 JSON 导出。接收方预览后添加独立副本。分享快照只包含角色配置，不包含会话、记忆、知识库或账号信息。更新分享会轮换随机码使旧链接失效；删除角色会级联删除分享。已有副本和导出文件不能撤销。

GET/POST/DELETE /api/characters/:id/share 由角色所有者管理。GET/POST /api/shares/:token 用于已登录账号预览和添加，随机码为 24 字节随机数的 base64url。未知或撤销的码返回 404。

当前仅本机服务；localhost 分享链接无法直接用于其他电脑。跨设备使用角色 JSON 文件导出与导入，文件不得超过 100 KB，自定义图片地址须在接收设备可访问。默认人物图片随应用内置。接收方需要自己安装对应聊天模型。

验证：默认三角色、重复读取不重复、删除不复生、跨账号管理拒绝、分享字段白名单、独立副本、撤销链接和副本保留的 HTTP 测试通过；25 项单元测试、规范和生产构建通过。
