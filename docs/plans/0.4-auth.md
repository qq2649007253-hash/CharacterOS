# 登录与角色权限

- 首次初始化创建管理员，无默认密码；已有未归属角色归首个管理员。
- 普通注册固定 user，管理员管理账号启停与角色，禁止降级或停用自己。
- Cookie 会话保存在服务端，退出和停用立即撤销；密码使用随机盐与 scrypt，禁止明文持久化。
- 每个账号只能访问自己角色关联的数据；管理员额外访问账号管理、全局运行轨迹和评测。
- 登录注册有请求频率限制，写请求必须 JSON，浏览器 Origin 必须匹配 Host。当前只监听 loopback。
- 验收覆盖匿名访问、越权、注册提权、退出、停用、旧数据迁移以及分页兼容。

验证记录（2026-09-15）：25 项单元测试、身份与权限 HTTP 集成测试、分页回归、类型检查、ESLint、前后端边界和生产构建通过。HTTP 测试覆盖匿名访问、首个管理员旧角色迁移、重复初始化、注册角色注入、普通用户管理接口拒绝、跨账号角色/消息读取与写入、注销与停用会话撤销、管理员自我降级拒绝。浏览器确认初始化页面正常；管理员和普通用户完整页面交互尚未做浏览器端验收。个人数据库已另存迁移前备份，未创建实际管理员密码。
