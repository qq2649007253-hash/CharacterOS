# 免费在线语音与原创立绘

用户选择：优先自然度且不付费，允许在线语音发送待朗读文本。

以 edge-tts 接入 Edge 在线语音，无 API 密钥。只发送待朗读文字与声线参数，不发送历史记录、记忆或图片。在线失败明确提示，不静默退回已被否定的本地声线。该社区接入没有生产 SLA，不能承诺永久免费或商业授权。

替换三位原创角色的默认插画为独立生成的场景立绘，保留角色 ID、人设与消息。图片存放 apps/web/public/companions。

验收：真实在线生成 MP3；前端支持 MP3；新的角色声线与图片持久化；类型、测试和生产构建。生成成功不替代用户听感确认。
